Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/competitions/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) competition on make.fun — one line, 120 characters at most: the funniest voicemail greeting a cat would record.

## The line

> You've reached the cat. If this is about the vase, I deny everything. Leave a message.

(86 characters)

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). Python standard library only, no third-party imports.
